🎮 Nim Game (Java)
* This project implements the classic mathematical strategy game Nim, a two-player game involving one or more piles of objects (such as stones or sticks). Players take turns removing objects from a single pile. The key rules:
  * On your turn, you must remove at least one object.
  * You may remove up to a certain maximum, depending on the rules.
  * The player who takes the last object wins (standard version) — or in some variations, loses (misère Nim).

🎯 Goal of the Project
* Use object-oriented programming to simulate the Nim game.
* Create separate classes for game control and each type of player.
* Implement a computer opponent that makes valid moves (strategy may be optimal or basic, depending on assignment instructions).
