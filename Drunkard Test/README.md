Drunkard's Random Walk: This project simulates a drunk person wandering randomly through an infinite city grid. The drunkard starts at a given (avenue, street) coordinate and takes random steps in the four cardinal directions.

🌐 Problem Overview
- The grid is defined using integer coordinates (x, y).
- Each step, the drunkard randomly moves:
  - North (y+1)
  - South (y−1)
  - East (x+1)
  - West (x−1)
- There is no boundary (infinite grid in all directions).
- The goal is to track the drunkard’s movement and calculate how far they have wandered from the starting point.
